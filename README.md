# 🏠 Airbnb Data Analysis & Price Optimization Dashboard

## 📌 Project Overview
This project analyzes Airbnb listings data using **Tableau** to evaluate pricing trends, listing counts across bedroom sizes, geographical price distributions by zip code, and overall revenue patterns over time.

---

## 📊 Dashboard Preview
![Airbnb Tableau Dashboard](Dashboard_Screenshot.png)

---

## Key Visualizations & Insights

1. **Average Price per Bedroom**:
   - Analyzes average pricing based on bedroom capacity, ranging from 1-bedroom (~$96.2) up to 6-bedroom listings (~$584.8).
2. **Distinct Count of Bedroom Listings**:
   - Break down of listing distribution by property size (1-bedroom listings account for the majority with 1,811 listings).
3. **Geographical Price Distribution (Map & Bar Chart)**:
   - Interactive map and zip code breakdown identifying top high-value neighborhoods and pricing clusters.
4. **Revenue Trends over Time**:
   - Tracks annual price and revenue fluctuations across weekly periods throughout the year.
